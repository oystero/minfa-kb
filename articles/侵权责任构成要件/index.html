侵权责任构成要件

03-侵权责任 2026/05/28 1528字 4 分钟阅读
#民法#侵权责任#构成要件#违法行为#损害事实#因果关系#过错

概述

侵权责任构成要件是判断行为人是否承担侵权责任的标准。我国侵权责任法采用四要件说，即违法行为、损害事实、因果关系和主观过错。掌握侵权责任构成要件是处理侵权纠纷的基础。

核心内容

一、法律依据

条文 内容要点
《民法典》第1165条 过错责任的构成要件
《民法典》第1166条 无过错责任的构成要件

二、四要件体系

1. 违法行为

类型 具体内容 典型情形
作为 积极实施侵害行为 殴打、诽谤、盗窃
不作为 未履行法定义务 未尽安全保障义务、未尽监护职责

2. 损害事实

类型 具体内容 典型情形
人身损害 生命权、身体权、健康权受侵害 受伤、残疾、死亡
财产损害 财产权受侵害 财物毁损、财产减少
精神损害 精神痛苦 侵害人格权造成的精神痛苦

3. 因果关系

类型 具体内容 认定标准
直接因果关系 违法行为直接导致损害 条件说+相当因果关系说
间接因果关系 违法行为通过中介因素导致损害 相当因果关系说

4. 主观过错

类型 具体内容 认定标准
故意 明知会发生损害而希望或放任 主观状态
过失 应当预见而未预见，或已预见而轻信能够避免 客观标准（合理人标准）

三、举证责任分配

要件 证明责任 证明标准
违法行为 被侵权人 高度盖然性
损害事实 被侵权人 高度盖然性
因果关系 被侵权人 高度盖然性
主观过错 被侵权人（过错责任）/推定（过错推定） 高度盖然性

四、裁判规则

规则 要旨 实务指引
四要件缺一不可 四个要件必须同时具备 全面收集证据
举证责任分配 被侵权人承担举证责任 保留证据
因果关系认定 采用相当因果关系说 证明行为与损害的关联性
过错认定 采用客观标准（合理人标准） 证明行为人未尽合理注意义务

五、实务要点

  1. 证据收集：全面收集违法行为、损害事实、因果关系、过错的证据
  2. 举证策略：根据归责原则确定举证重点
  3. 因果关系证明：采用相当因果关系说
  4. 过错证明：采用客观标准（合理人标准）

典型案例

案例：交通事故受害人特殊体质不属于可以减轻侵权人责任的法定情形

案号：指导案例第24号 / （2013）锡民终字第497号 审理法院：江苏省无锡市中级人民法院 裁判日期：2013年6月21日 来源：指导案例24号——维基文库 · 中国法学网分析

案情概要：王阳驾驶机动车在人行横道线处碰擦行人荣宝英致其受伤。荣宝英年事已高、骨质疏松，经鉴定伤残等级为九级和十级，但鉴定意见将"损伤参与度评定为75%，其个人体质的因素占25%"。一审法院据此扣减25%残疾赔偿金。

裁判要旨：交通事故的受害人没有过错，其体质状况对损害后果的影响不属于可以减轻侵权人责任的法定情形。受害人年老骨质疏松仅是事故造成后果的客观因素，并无法律上的因果关系。不应因受害人个人体质状况对交通事故导致的伤残存在一定影响而自负相应责任。

与知识点的关联分析：本案是侵权责任构成要件中"因果关系"认定的经典案例。法院区分了病理上的因果关系与侵权法领域的责任因果关系，明确受害人特殊体质不构成法律上的"过错"，不适用过失相抵。本案涉及四要件中"因果关系"和"主观过错"的认定标准，体现了相当因果关系说在司法实践中的适用。
