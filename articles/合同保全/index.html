合同保全

合同法 2026/05/28 2473字 7 分钟阅读
#民法#合同法#合同履行#合同保全#代位权#撤销权

概述

合同保全是债权人在债务人怠于行使权利或不当处分财产、危及债权实现时的法定救济手段。核心工具是代位权和撤销权——前者解决"债务人有权利却不行使"的问题，后者解决"债务人不当处分财产"的问题。实务中，合同保全常用于执行难案件，是债权人突破"合同相对性"限制的重要武器。

核心内容

一、法律依据

条文 内容
第535条 代位权——债务人怠于行使其到期债权或有关从权利，影响债权人到期债权实现的，债权人可以向法院请求以自己的名义代位行使
第536条 保存行为的代位——债权人的债权到期前，债务人的权利存在诉讼时效期间届满或未及时申报破产债权等情形的，债权人可以代位向相对人请求
第537条 代位权的效力——代位权成立的，由相对人向债权人履行义务；多个债权人的，按照债权比例清偿
第538条 撤销权（无偿处分）——债务人无偿处分财产权益影响债权实现的，债权人可以请求法院撤销
第539条 撤销权（有偿处分）——债务人以明显不合理低价转让财产或以明显不合理高价受让财产，且相对人知道或应当知道的，债权人可以请求撤销
第540条 撤销权的行使范围——以债权人的债权为限，行使撤销权的必要费用由债务人负担
第541条 撤销权的除斥期间——自债权人知道或应当知道撤销事由之日起一年内行使，自债务人行为发生之日起五年内没有行使的消灭

二、代位权

1. 构成要件

要件 具体要求
债权合法 债权人对债务人的债权合法有效
债务人怠于行使权利 债务人未以诉讼或仲裁方式向次债务人主张权利
影响债权实现 债务人怠于行使权利的行为影响债权人债权的实现
权利非专属 代位行使的权利不属于债务人自身（如人身损害赔偿请求权）

2. "怠于行使"的认定

  • 核心标准： 债务人未以诉讼或仲裁方式向次债务人主张权利
  • 不考虑因素： 债务人是否以其他方式（如催告、协商）主张过权利不影响"怠于"的认定
  • 举证责任： 债务人或次债务人主张债务人已行使权利的，应承担举证责任

3. 代位权的行使方式

债权人 -> 以自己名义起诉 -> 以债务人为被告，次债务人为第三人
        -> 法院认定代位权成立 -> 次债务人直接向债权人履行

4. 代位权的效力（第537条）

情形 效力
代位权成立 相对人（次债务人）直接向债权人履行
多个债权人 按照各债权人的债权比例清偿
履行后 债权人与债务人、债务人与相对人之间相应的债权债务关系消灭

三、撤销权

1. 构成要件

无偿处分（第538条）：

要件 具体要求
债务人无偿处分 放弃债权、放弃债权担保、无偿转让财产、恶意延长到期债权的履行期
影响债权实现 债务人的处分行为导致其责任财产减少，影响债权实现
相对人主观 不要求相对人知道或应当知道（善意亦可撤销）

有偿处分（第539条）：

要件 具体要求
债务人有偿处分 以明显不合理低价转让、以明显不合理高价受让、为他人的债务提供担保
影响债权实现 同上
相对人主观 相对人知道或应当知道该情形

2. "明显不合理"的价格判断

根据司法解释，转让价格低于交易时交易地的指导价或市场交易价**70%的，一般可以视为明显不合理低价；转让价格高于当地指导价或市场交易价30%**的，一般可以视为明显不合理高价。

3. 撤销权的除斥期间（第541条）

起算点 期间 性质
知道或应当知道撤销事由之日 1年 除斥期间，不适用中断、中止
债务人行为发生之日 5年 最长除斥期间

四、裁判规则

序号 裁判规则 裁判要旨
1 代位权诉讼的管辖 由被告（次债务人）住所地法院管辖，不受债务人与次债务人之间仲裁条款的约束
2 代位权的范围限制 代位行使的权利范围以债权人的到期债权为限，超出部分不予支持
3 撤销权与善意取得 撤销权的行使不影响善意第三人的合法权利，但无偿处分的相对人不适用善意取得
4 撤销权的行使范围 撤销的范围以债权人的债权为限，不能撤销债务人的全部处分行为
5 代位权与执行程序的衔接 债权人在执行程序中发现债务人有到期债权的，可以申请代位执行
6 债务人放弃时效抗辩 债务人放弃对次债务人的时效抗辩，损害债权人利益的，债权人可以行使撤销权

典型案例

案例：债务人通过不动产交易转移财产——债权人撤销权的行使

案号/入库编号：入库编号：2024-18-2-078-001；案号：（2023）鲁0682民初2467号

审理法院：山东省某基层人民法院

基本案情：严某诉某石油公司、王某甲等债权人撤销权纠纷案。债务人在明知负有债务的情况下，通过不动产交易将名下财产转移至关联人名下，债权人严某发现后提起撤销权诉讼。

裁判要旨：债务人在明知负有债务的情况下，以明显不合理低价转让不动产，受让人知道或应当知道该情形的，债权人有权请求法院撤销该转让行为。

实务要点：

  1. 债务人以明显不合理低价转让财产（低于市场价70%），债权人可行使撤销权
  2. 有偿处分情形下，撤销权的成立以相对人"知道或应当知道"为要件
  3. 撤销权的行使范围以债权人的债权为限
  4. 撤销权自债权人知道或应当知道撤销事由之日起一年内行使

与知识点的关联：本案是《民法典》第539条撤销权规定的典型案例，体现了有偿处分情形下债权人撤销权的构成要件和行使规则。

实务操作建议

  1. 代位权诉讼的策略： 起诉前充分调查次债务人的偿债能力，避免胜诉后无法执行
  2. 撤销权的时间管理： 发现债务人不当处分财产后，应在一年内提起诉讼，避免除斥期间届满
  3. 证据收集： 关注债务人的工商变更登记、不动产登记变动、诉讼信息等，及时发现保全机会
  4. 与执行程序的配合： 在执行程序中发现债务人有到期债权或不当处分行为的，可以同时申请代位执行和撤销权诉讼
