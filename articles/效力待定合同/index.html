效力待定合同

合同法 2026/06/04 3844字 10 分钟阅读
#民法#合同法#合同效力#效力待定#无权代理#限制行为能力#行政审批

概述

效力待定合同是指合同虽已成立，但因主体资格欠缺（限制行为能力人、无权代理人、无权处分人）或法律规定须经批准等特殊生效要件，而效力悬而未决，有待有权人追认、拒绝或审批机关批准、不批准才能确定其最终效力的合同。与无效合同不同，效力待定合同有"治愈"的可能；与可撤销合同不同，效力待定合同的最终效力取决于第三人（追认权人或审批机关）而非当事人自身。该制度的核心价值在于：在保护限制行为能力人、被代理人利益的同时，兼顾交易安全和善意相对人的合理期待。

核心内容

法律依据

条文 内容要点
第145条 限制民事行为能力人实施的纯获利益或与其年龄/智力/精神状况相适应的行为有效；其他行为须法定代理人追认
第171条 无权代理行为未经被代理人追认对被代理人不发生效力；善意相对人有权撤销；行为人承担履行或赔偿责任
第172条 表见代理——相对人有理由相信代理人有代理权的，代理行为有效
第503条 无权代理人以被代理人名义订立合同，被代理人已开始履行的，视为追认
第152条 追认权的行使期限参照适用撤销权的除斥期间
第502条第2款 须办理批准等手续的合同，未办理的不影响报批义务等条款的效力

效力待定合同的类型

类型 法律依据 效力确定主体 效力确定方式
限制行为能力人签订的合同 第145条 法定代理人 明示追认或默示追认
无权代理签订的合同 第171条 被代理人 明示追认或以行为追认
无权处分签订的合同 第311条（善意取得参照） 权利人 明示追认或以行为追认
须经批准生效的合同 第502条第2款 审批机关 批准或不批准

构成要件

一、限制行为能力人签订的合同

  1. 行为人系8周岁以上的未成年人或不能完全辨认自己行为的成年人
  2. 实施的行为不属于纯获利益的行为（如接受赠与）
  3. 实施的行为与其年龄、智力、精神状况不相适应
  4. 法定代理人未事先同意

二、无权代理签订的合同

  1. 行为人没有代理权（自始无权）、超越代理权或代理权终止后仍以被代理人名义行事
  2. 行为人以被代理人名义签订合同
  3. 不构成表见代理（第172条）

三、无权处分签订的合同

  1. 处分人对标的物无处分权
  2. 以自己名义签订合同（区别于无权代理以他人名义签订）

四、须经批准生效的合同

  1. 法律、行政法规规定合同应当办理批准等手续方能生效（第502条第2款）
  2. 当事人尚未办理批准等手续
  3. 合同已依法成立（双方意思表示一致）
  4. 常见类型：采矿权转让、国有资产转让、外商投资企业变更、金融企业股权转让（超过一定比例）等

裁判规则

裁判规则 说明
追认的方式 可明示（书面/口头同意）或默示（实际履行、接受履行等）
追认的溯及力 追认后合同自成立时生效，而非从追认时生效
善意相对人的撤销权 在追认前，善意相对人有权以通知方式撤销合同（《民法典》第171条第2款）
善意的认定标准 "善意"指不知道且不应当知道行为人无权，相对人负有基本审查义务
无权处分不影响合同效力 《民法典》第597条明确：无权处分不影响合同效力，合同不因处分人无处分权而无效
善意取得的衔接 无权处分合同中，如受让人符合善意取得要件，可取得物权
表见代理的优先适用 如相对人有理由相信行为人有代理权，直接适用《民法典》第172条（表见代理），合同有效，无须追认
催告追认的期限 相对人可催告追认权人在30日内追认，未作表示视为拒绝追认
须批准合同的效力状态 须经批准的合同未批准的，属于"未生效"而非"无效"；报批义务条款独立生效（《民法典》第502条第2款）
不履行报批义务的后果 负有报批义务的一方不履行报批义务的，对方可请求继续履行或解除合同并赔偿损失（合同编通则司法解释第12条）

追认与拒绝的法律后果

效力待定合同
    │
    ├── 类型一至三：主体资格欠缺
    │   │
    │   ├── 追认 → 合同自成立时生效（溯及力）
    │   │
    │   ├── 拒绝追认 → 合同确定无效
    │   │       ├── 限制行为能力人：法定代理人不追认
    │   │       └── 无权代理：被代理人不追认
    │   │               └── 善意相对人→可请求行为人履行或赔偿
    │   │               └── 恶意相对人→与行为人按过错分担
    │   │
    │   └── 善意相对人撤销 → 合同确定无效（追认前撤销）
    │
    └── 类型四：须经批准生效
        │
        ├── 批准 → 合同生效
        │
        └── 不批准 → 合同确定不生效
                └── 报批义务条款独立生效→可主张违约责任
                └── 无报批条款→可主张缔约过失责任

实务要点

  1. 限制行为能力人的"适应性"判断：应综合考虑行为性质（日常生活交易还是重大财产处分）、金额大小、当地生活水平等因素。16周岁以上以自己劳动收入为主要生活来源的视为完全行为能力人。
  2. 追认的举证：主张对方已追认的一方应承担举证责任。默示追认（如实际履行）需要有明确的行为证据，单纯的沉默一般不构成追认。
  3. 无权代理中善意相对人的救济路径：被代理人拒绝追认的，善意相对人可选择：（1）请求行为人履行合同义务；（2）请求行为人赔偿损失（赔偿范围不超过被代理人追认时相对人所能获得的利益）。
  4. 表见代理与无权代理的竞合：相对人主张表见代理的，应就"有理由相信"承担举证责任。实务中常见证据包括：介绍信、盖章的空白合同、以往交易习惯等。
  5. 无权处分合同的独立效力：即使出卖人无权处分，买卖合同本身有效，买受人可主张违约责任。这是《民法典》第597条对"处分行为与负担行为"区分原则的确认。
  6. 公司越权担保的效力：法定代表人超越权限订立的担保合同，相对人善意的（不知且不应知超越权限），担保合同有效（九民纪要第17-20条）。
  7. 须经批准生效合同的效力状态：此类合同在批准前处于"成立但未生效"状态，不同于"无效"。报批义务条款独立生效，负有报批义务的一方不履行的，对方可请求其继续履行或解除合同并赔偿损失（合同编通则司法解释第12条）。详见典型案例（指导案例123号）。相关深度分析另见合同成立与生效。

典型案例

案例一：于红岩与锡林郭勒盟隆兴矿业有限责任公司执行监督案（指导案例123号）

案号：（2017）最高法执监136号

类型：最高人民法院指导案例（2019年12月24日发布）

来源：最高人民法院权威发布

基本案情：2008年8月，隆兴矿业与于红岩签订《矿权转让合同》，约定将采矿权有偿转让给于红岩。于红岩依约支付了转让费150万元并进行了采矿工作，但隆兴矿业未按约办理矿权转让手续。双方发生纠纷后，法院认定：《矿权转让合同》系双方真实意思表示，合同依法成立，但因采矿权转让须经行政审批机关批准，该合同尚未生效。二审法院进一步指出：“双方签订的《矿权转让合同》尚未办理批准、登记手续，故《矿权转让合同》依法成立，但未生效，该合同的效力属效力待定。”

裁判要旨：

  1. 须经行政审批方能生效的合同，虽已成立但未生效，其效力属效力待定——取决于审批机关是否批准
  2. 合同未生效不影响合同中履行报批义务条款的效力，转让方仍应按照合同约定办理报批手续
  3. 采矿权转让涉及行政机关审批和许可，不同于一般民事权利，受让人资格审查属行政审批权力，非法院职权范围

与效力待定合同的关联分析：

本案展示了效力待定合同的第四种类型——“须经批准生效的合同”。与前三类效力待定合同（因主体资格欠缺）不同，此类合同的效力悬而未决并非因为主体资格欠缺，而是因为法律、行政法规规定须经批准方能生效（现《民法典》第502条第2款）。在批准之前，合同处于"成立但未生效"的效力待定状态：

  • 批准 → 合同生效（溯及至成立时）
  • 不予批准 → 合同确定不生效，当事人可主张缔约过失责任或依报批条款主张违约责任

实务中常见的此类合同包括：采矿权转让合同、外商投资企业股权转让合同、国有资产转让合同、金融企业股权转让（超过一定比例）等。此类合同的特殊性在于，报批义务条款独立生效，负有报批义务的一方不履行报批义务的，对方可请求其继续履行或解除合同并赔偿损失（合同编通则司法解释第12条）。相关深度分析另见合同成立与生效。
