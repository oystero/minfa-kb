案例-物权新增制度

06-案例库 2026/05/28 5100字 13 分钟阅读
#民法#案例#物权编#物权新增制度#专题案例

概述

《中华人民共和国民法典》物权编在承继原《物权法》的基础上，增设了多项新制度，回应了社会经济发展和人民群众的实际需求。主要新增制度包括：居住权制度（第366-371条）、土地经营权制度（第339-342条，落实"三权分置"改革）、添附制度（第322条）、建筑物区分所有权制度的完善（第271-287条，降低业主表决门槛等）以及不动产登记错误赔偿制度（第222条）等。

本专题案例围绕上述新增制度，选取人民法院案例库中的真实案例进行分析。其中，居住权和建筑物区分所有权两个专题已检索到入库案例并附有完整案号；土地经营权、添附和不动产登记错误赔偿三个专题，经多渠道检索未能确认具有完整案号的真实案例，故暂不编造案号，仅作制度分析说明。

案例列表

案例一：居住权——杨某甲诉杨某乙、刘某言等继承纠纷案

案号：一审（2020）京0108民初46457号；二审（2021）京01民终10858号

入库编号：2025-07-2-476-002

来源：人民法院案例库

裁判要旨：1. 民法典施行前以遗嘱方式设立居住权，民法典施行后请求确认居住权的，适用民法典的规定。2. 遗嘱继承中，被继承人在遗嘱中为第三人在其所有的住宅上设立居住权益，且该第三人在被继承人死亡前已实际占有使用该住宅的，应认定居住权设立有效。3. "他人的住宅"应作扩大解释，不限于第三人所有的住宅。

案情简介： 被继承人杨某与前妻育有一子杨某甲。杨某与刘某言再婚后，杨某名下有一套房屋。杨某生前立下遗嘱，载明在其去世后，刘某言有权在其房屋中居住至终老，任何人不得干涉。杨某去世后，杨某甲作为唯一法定继承人，主张继承该房屋的全部产权，并要求刘某言搬离。刘某言主张其依据杨某的遗嘱享有居住权，有权继续在该房屋中居住。

裁判理由：

💡 本院认为（基于人民法院案例库公开信息整理）
> "杨某在遗嘱中明确表达了在其去世后由刘某言在其房屋中居住至终老的真实意思，刘某言在杨某去世前已实际在该房屋中居住生活。居住权是民法典新设的用益物权类型，虽然杨某设立遗嘱的行为发生在民法典施行之前，但刘某言请求确认居住权发生在民法典施行之后，根据《最高人民法院关于适用〈中华人民共和国民法典〉时间效力的若干规定》第三条的规定，民法典施行前的法律事实引起的民事纠纷案件，当时的法律、司法解释没有规定而民法典有规定的，可以适用民法典的规定。居住权制度属于民法典新增制度，原《物权法》等法律没有规定，故本案可以适用民法典关于居住权的规定。杨某以遗嘱方式为刘某言设立居住权的意思表示明确，刘某言亦已实际占有使用该住宅，居住权设立有效。"

实务要点：

  1. 民法典新增制度的时间效力适用规则：民法典施行前的法律事实，当时的法律没有规定而民法典有规定的，可以适用民法典（空白溯及）
  2. 遗嘱设立居住权属于民法典第371条规定的"以遗嘱方式设立居住权"，是居住权设立的法定方式之一
  3. 居住权的"他人住宅"应作扩大解释，不仅限于第三人所有的住宅，被继承人在自己所有的住宅上为他人设立居住权亦属有效
  4. 居住权人已实际占有使用住宅的事实，是认定居住权设立有效的重要考量因素

案例分析： 本案是人民法院案例库入库案例，具有重要的类案参考价值。该案明确了三个关键问题：一是民法典居住权制度的空白溯及适用问题，为处理民法典施行前遗留的居住权益纠纷提供了裁判路径；二是遗嘱设立居住权的效力认定问题，确认了被继承人在自己所有的住宅上为他人设立居住权的合法性；三是"他人住宅"的扩大解释问题。实务中，在处理类似继承纠纷时，应注意审查遗嘱中居住权设立的意思表示是否明确、居住权人是否已实际占有使用住宅、以及居住权是否损害了其他继承人的基本生活保障等因素。

案例二：建筑物区分所有权——梅州市梅江区某业主委员会诉梅州市梅江区某房地产开发有限公司、杜某某建筑物区分所有权纠纷案

案号：（2014）粤高法民一提字第120号

入库编号：2023-16-2-045-002

来源：人民法院案例库

裁判要旨：建设单位按照规划建设的车位、车库，在扣除规划用于停放汽车的车位、车库后，占用业主共有道路或者其他共有场地用于停放汽车的车位，属于业主共有。建设单位将属于业主共有的车位出售给他人的，构成无权处分，该买卖合同无效。

案情简介： 梅州市梅江区某房地产开发有限公司（以下简称"开发公司"）在开发建设某小区时，将部分停车位出售给杜某某等业主。某业主委员会成立后发现，开发公司出售的部分停车位系占用小区公共道路和绿地建设，依法应属于全体业主共有，开发公司无权出售，遂提起诉讼，请求确认开发公司与杜某某之间的停车位买卖合同无效，并要求杜某某返还所占停车位。

裁判理由：

💡 本院认为（基于人民法院案例库公开信息整理）
> "根据《物权法》第七十三条（现《民法典》第二百七十四条）的规定，建筑区划内的道路、绿地以及其他公共场所、公用设施和物业服务用房，属于业主共有。占用业主共有的道路或者其他场地用于停放汽车的车位，属于业主共有。本案中，开发公司出售的部分停车位系占用小区公共道路和绿地建设而成，依法应归全体业主共有。开发公司将属于业主共有的停车位出售给杜某某，属于无权处分，且未经业主大会或者业主委员会追认，该买卖合同无效。"

实务要点：

  1. 建筑区划内的车位、车库权属应区分情况认定：规划用于停放汽车的车位、车库，由当事人通过出售、附赠或者出租等方式约定；占用业主共有道路或其他共有场地的车位，属于业主共有
  2. 建设单位将属于业主共有的车位出售给他人的，构成无权处分，买卖合同无效
  3. 业主委员会有权代表全体业主就侵害共有权的行为提起诉讼
  4. 民法典第278条将业主共同决定事项的表决门槛由"双三分之二以上"降低为"双过半数"，有利于业主维权

案例分析： 本案是建筑物区分所有权领域的入库案例，明确了占用业主共有道路和绿地建设的停车位归属全体业主共有的裁判规则。该案对于规范开发商行为、保护业主共有权具有重要意义。民法典在原《物权法》基础上，对建筑物区分所有权制度作了多项完善：一是第277条增加规定居委会对设立业主大会、选举业委会的指导和协助义务；二是第278条降低了业主共同决定事项的表决门槛，将使用维修资金等事项的表决要求由"双三分之二以上"同意修改为"双过半数"同意；三是第281条完善了维修资金的使用和管理规则。实务中，业主委员会在维权时应注意收集规划文件、竣工验收资料等证据，以证明涉案车位是否属于规划内车位还是占用共有场地的车位。

案例三：土地经营权——制度分析说明

ℹ️ 检索说明
> 经多渠道检索，未找到人民法院案例库中以民法典第339条（土地经营权流转）为核心裁判依据的入库案例。以下仅作制度分析，不编造案号。

相关法条：《民法典》第339-342条

制度要点：

土地经营权是民法典物权编落实农村承包地"三权分置"改革的重要制度安排。第339条规定，土地承包经营权人可以自主决定依法采取出租、入股或者其他方式向他人流转土地经营权。第340条规定，土地经营权人有权在合同约定的期限内占有农村土地，自主开展农业生产经营并取得收益。第341条规定，流转期限为五年以上的土地经营权，自流转合同生效时设立，当事人可以向登记机构申请土地经营权登记；未经登记，不得对抗善意第三人。

实务要点：

  1. 土地经营权是土地承包经营权派生的权利，属于"三权分置"（所有权、承包权、经营权）框架下的新型权利
  2. 土地经营权的流转方式包括出租、入股以及其他方式（如土地托管、代耕代种等）
  3. 流转期限五年以上的土地经营权具有登记能力，自流转合同生效时设立（登记对抗主义）
  4. 土地经营权可以用于融资担保，但须依法办理登记

案例四：添附制度——制度分析说明

ℹ️ 检索说明
> 经多渠道检索，未找到人民法院案例库中以民法典第322条（添附制度）为核心裁判依据的入库案例。以下仅作制度分析，不编造案号。

相关法条：《民法典》第322条

制度要点：

民法典第322条首次在法律层面确立了添附制度，规定因加工、附合、混合而产生的物的归属，有约定的按照约定；没有约定或者约定不明确的，依照法律规定；法律没有规定的，按照充分发挥物的效用以及保护无过错当事人的原则确定。因一方当事人的过错或者确定物的归属造成另一方当事人损害的，应当给予赔偿或者补偿。

实务要点：

  1. 添附包括附合（动产与不动产附合、动产与动产附合）、混合和加工三种类型
  2. 添附物归属的确定规则：约定优先→法律规定→充分发挥物的效用+保护无过错当事人
  3. 添附制度解决了不同所有人的物结合为一物后的权属争议，是物权法的重要组成部分
  4. 《民法典担保制度解释》第41条进一步明确了抵押财产发生添附时抵押权的效力范围
  5. 实务中常见的添附纠纷包括：装修装饰、建筑材料附合于土地、加工他人原材料等

案例五：不动产登记错误赔偿——制度分析说明

ℹ️ 检索说明
> 经多渠道检索，未找到人民法院案例库中以民法典第222条（不动产登记错误赔偿）为核心裁判依据的入库案例。以下仅作制度分析，不编造案号。

相关法条：《民法典》第222条

制度要点：

民法典第222条规定：当事人提供虚假材料申请登记，造成他人损害的，应当承担赔偿责任。因登记错误，造成他人损害的，登记机构应当承担赔偿责任。登记机构赔偿后，可以向造成登记错误的人追偿。该条确立了不动产登记错误的双轨赔偿机制：一是虚假材料提供者的民事赔偿责任；二是登记机构的赔偿责任（通说认为属于国家赔偿责任）。

实务要点：

  1. 不动产登记错误赔偿分为两条路径：当事人提供虚假材料的民事赔偿责任和登记机构的赔偿责任
  2. 登记机构赔偿责任的性质为国家赔偿责任，适用《国家赔偿法》的规定
  3. 登记机构赔偿后有权向造成登记错误的人追偿
  4. 赔偿范围一般限于直接损失，不包括间接损失和可得利益损失
  5. 实务中，受害人可选择行政附带民事诉讼程序一并解决登记错误赔偿和相关民事争议

裁判规则总结

案例 核心规则 法律依据 适用场景
案例一（2025-07-2-476-002） 民法典施行前以遗嘱方式设立居住权的，适用民法典居住权规定 民法典第366-371条、时间效力规定第3条 继承纠纷中的居住权确认
案例二（2023-16-2-045-002） 占用业主共有道路、绿地建设的车位属于业主共有，开发商出售构成无权处分 民法典第274条、第275条 小区停车位权属争议
土地经营权（制度说明） 土地承包经营权人流转土地经营权的方式包括出租、入股等 民法典第339-342条 农村土地"三权分置"纠纷
添附制度（制度说明） 添附物归属按"约定→法律规定→物的效用+无过错保护"规则确定 民法典第322条 不动产装修、材料附合等纠纷
登记错误赔偿（制度说明） 登记机构因登记错误造成损害的应承担赔偿责任，可追偿 民法典第222条 不动产登记错误损害赔偿

实务启示

  1. 居住权的设立方式：居住权可以通过合同方式或遗嘱方式设立，均须采用书面形式。以遗嘱方式设立居住权的，居住权自遗嘱生效时设立。建议在遗嘱中明确居住权的具体内容（如住宅位置、居住期限、使用范围等），避免后续争议。

  2. 建筑物区分所有权的业主维权：业主委员会是代表全体业主维护共有权益的重要组织。民法典降低了业主共同决定事项的表决门槛，有利于业主行使权利。实务中，业主应积极参与业主大会，及时成立业主委员会，对开发商侵占共有部分的行为及时维权。

  3. 土地经营权流转的规范操作：土地承包经营权人流转土地经营权时，应签订书面流转合同，明确流转期限、用途、费用等事项。流转期限五年以上的，建议申请土地经营权登记，以保障权利的对抗效力。

  4. 添附纠纷的处理思路：处理添附纠纷时，应首先审查当事人之间是否有约定，其次依据法律规定，最后按照充分发挥物的效用和保护无过错当事人的原则确定归属。对于因添附导致的损失，应由过错方承担赔偿责任。

  5. 不动产登记错误的救济途径：因登记错误受到损害的权利人，可以选择向提供虚假材料的当事人主张民事赔偿，也可以向登记机构主张国家赔偿。两种救济途径的归责原则、赔偿范围和程序要求不同，应根据具体情况选择最优救济方案。
